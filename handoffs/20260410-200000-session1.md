## What Was Done

### 1A. Date Format AM/PM Bug (Issue 1)

**File:** `QuickCopyButtons.swift`

Added `formatter.locale = Locale(identifier: "en_US_POSIX")` to the `dateString` computed property. This ensures the 24-hour format "yyyyMMdd:HHmm" is respected regardless of the user's system locale preferences.

### 1B. Right-Align All Buttons (Issue 2)

**File:** `ContentView.swift`

Moved `Spacer()` to the first position in the `controlBarContent` HStack. Added a filename display (`Text(fileURL?.lastPathComponent ?? "Untitled")`) on the left side so the user can still see which document they're editing.

New layout: `[filename] [Spacer] [QuickCopy] [Divider] [ModeButtons] [Divider] [ToggleButtons]`

### 1C. Collapse Navbar to Single Line (Issue 3)

**File:** `ClearlyApp.swift`

Changed `.windowToolbarStyle(.unifiedCompact(showsTitle: true))` to `.windowToolbarStyle(.unifiedCompact(showsTitle: false))`. This hides the native toolbar title, leaving only the traffic lights and the custom control bar as the single visible row.

### 1D. Restyle Mode Picker as Flat Buttons (Issue 4)

**File:** `ContentView.swift`

Replaced the segmented `Picker("Mode", selection: $mode)` with three individual `controlBarButton()` calls:
- `controlBarButton("pencil", active: mode == .edit)`
- `controlBarButton("rectangle.split.2x1", active: mode == .split)`
- `controlBarButton("eye", active: mode == .preview)`

This makes the mode buttons visually consistent with the toggle buttons (flat, small SF Symbols).

### 1E. Style S1/S2/S3 as Visible Buttons (Issue 5)

**File:** `QuickCopyButtons.swift`

Added a subtle rounded border to the S1/S2/S3 buttons:
```swift
.background(
    RoundedRectangle(cornerRadius: 3)
        .stroke(Color.secondary.opacity(0.3), lineWidth: 0.5)
)
```

Also increased width from 22 to 26 to accommodate the border padding.

### 1F. Remove "MO/DE" Label (Issue 6)

**Automatically resolved** by 1D -- the Picker with its "Mode" label was removed entirely.
