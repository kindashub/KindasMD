## What Was Done

### Issue 6: Match TextEdit Font Rendering

**Root cause:** TextEdit uses Menlo 12pt with zero extra line spacing. KindasMD was using 16pt with lineSpacing: 3 and dimmer text.

**Changes:**
1. **Theme.swift:**
   - `editorFontSize` fallback: `16` → `12`
   - `lineSpacing`: `3` → `0`
   - Dark `textColor`: `0.878` → `0.95` (brighter white)

2. **All @AppStorage fontSize defaults changed from 16 to 12:**
   - ContentView.swift
   - ClearlyApp.swift (3 locations: FontSizeCommands, ExportPDFCommand, PrintCommand)
   - SettingsView.swift
   - ScratchpadContentView.swift
   - EditorView.swift (parameter default)
   - ScratchpadEditorView.swift (parameter default)

3. **UserDefaults Migration (ClearlyApp.swift):**
   - Added `migrateFontSizeIfNeeded()` that removes stored `16.0` values so new `12` default takes effect
   - Called from `init()`

### Issue 5: Default View State (All Toggles OFF)

**Root cause:** `@AppStorage` persisted toggles globally across ALL documents. User wants clean slate per document.

**Changes:**
1. **ContentView.swift:**
   - `@AppStorage("kindasBlueprintStripVisible")` → `@State private var boxStripVisible = false`
   - `@AppStorage("kindasMasterStripVisible")` → `@State private var masterStripVisible = false`
   - `@AppStorage("textEditBrowserVisible")` → `@State private var showTextEditBrowser = false`
   - Removed viewMode restoration from `init()` — always starts as `.edit`
   - Removed `onChange(of: mode)` handler that saved to UserDefaults

2. **ClearlyApp.swift:**
   - Removed `migrateKindasStripPrefsIfNeeded()` call and method (legacy migration for keys that no longer exist)

### Issue 1: Dock Launcher Fix

**Problem:** Launch failed with `RBSRequestErrorDomain Code=5` — stale processes were interfering.

**Fix:** Killed zombie KindasMDEditor processes. The build script already handles everything correctly; the issue was stale app instances blocking new launches.

- Dock launch confirmed working
