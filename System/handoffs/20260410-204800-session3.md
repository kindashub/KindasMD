### 3B. Box Palette Expansion (Issue 4)

**File:** `KindasStripView.swift`

- Updated `KindasBoxGridConfig`:
  - `rowCount`: 5 → 6
  - `cellCount`: 205 → 194 (4×41 + 20 + 10)
  - Added `row5Columns = 20`, `row6Columns = 10`
  - Added `row5CharLimit = 2`, `row6CharLimit = 4`
  - Updated `defaultCells()` with defaults for new rows (box-drawing pairs, patterns)
  - Updated `normalizeCell()` to accept `maxLength` parameter
  - Added `charLimit(forIndex:)` helper
  - Added `columns(forRow:)` helper
- Updated `BoxCharacterPaletteView`:
  - Separate rendering for rows 1-4 (41 cols, 1:1 aspect), row 5 (20 cols, 2:1 aspect), row 6 (10 cols, 4:1 aspect)
  - Adjusted font scaling for multi-character cells
- Updated `BoxCharacterEditGridView`:
  - Same row structure as palette view
  - Uses `charLimit` for proper text normalization

**File:** `ContentView.swift`

- Updated `loadBoxCells()` with smart migration:
  - Old format (205 cells): keeps rows 1-4, appends defaults for new rows 5-6
  - New format (194 cells): uses as-is
  - Invalid count: uses full defaults
