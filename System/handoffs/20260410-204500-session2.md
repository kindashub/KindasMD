## What Was Done

### Goal
Move all toolbar controls from native SwiftUI ToolbarItem into a custom HStack control bar in the content area. Remove WindowKindasBuildSubtitle. Use .unifiedCompact(showsTitle: true) for the native toolbar (now title-only). Style the custom bar with flat, small, oldschool buttons. All buttons must be visible at 500pt window width.

### Changes Made

**1. ContentView.swift:**

- **Removed** `WindowKindasBuildSubtitle` struct entirely (lines 125-146 previously)
- **Removed** `.background(WindowKindasBuildSubtitle())` from `contentWithModifiers`
- **Removed** entire `toolbarContent` computed property (previously lines 323-398)
- **Removed** `.toolbar { toolbarContent }` from `contentWithEventHandlers`
- **Added** new `controlBarContent` view (HStack with controls)
- **Added** `controlBarButton()` helper function for consistent flat button styling
- **Inserted** `controlBarContent` + `Divider()` at the top of `mainContent` VStack

The new control bar layout:
```
[Mode Picker] | [QuickCopyButtonsView] ----spacer---- [Characters] [MASTER] [Folder] [Outline] [Find]
```

**2. ClearlyApp.swift:**

- Changed `.windowToolbarStyle(.unified(showsTitle: true))` to `.windowToolbarStyle(.unifiedCompact(showsTitle: true))`

### Control Bar Design

- **Mode picker:** 100pt wide, segmented style, small control size
- **Quick Copy:** Uses existing QuickCopyButtonsView (to be redesigned in Session 3)
- **Toggle buttons:** 22x20pt plain buttons with 11pt SF Symbols
- **Spacing:** 6pt between elements, 8pt horizontal padding, 4pt vertical padding
- **Height:** ~28pt total bar height
- **Style:** Flat, no borders, no rounded rects, no hover backgrounds

## Architectural Context for Future Sessions

**CRITICAL for Session 3/4 agents:**

All controls are now in the **custom control bar** (`controlBarContent` HStack), NOT in native ToolbarItem.

- `controlBarContent` is defined as a private computed property in ContentView.swift
- It is placed at the top of the `mainContent` VStack (before FindBarView)
- `QuickCopyButtonsView()` is rendered inside this HStack between the mode picker divider and the Spacer
- The `controlBarButton()` helper provides consistent styling for toggle buttons
- There are NO more ToolbarItem entries in ContentView

When adding new controls (Session 3 Quick Copy redesign, Session 4 browser features), place them in `controlBarContent`, NOT in a ToolbarItem.
